# 🌈 Настроение

**Дневник настроения с поиском закономерностей.**

### ▶️ [Открыть](https://mmmaksmog-commits.github.io/mood-diary/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Пять уровней настроения и факторы дня
- Заметки и редактирование любого прошлого дня
- Календарь месяца с эмодзи
- Аналитика: среднее, распределение и влияние каждого фактора
- Светлая и тёмная тема

## Стек

JavaScript, CSS Grid, localStorage. Без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/mood-diary.git
cd mood-diary
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
